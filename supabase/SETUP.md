# ตั้งค่า Supabase สำหรับ FLOWLOCK

1. สร้างโปรเจกต์ Supabase แล้วเปิด SQL Editor
2. วางและรัน `supabase/setup.sql` (สคริปต์จะสร้าง private bucket สำหรับรูปโปรไฟล์ด้วย)
3. ใน Authentication settings ให้ปิดการยืนยันอีเมล (Confirm email) เนื่องจาก FLOWLOCK ใช้ชื่อผู้ใช้ ไม่ได้เก็บอีเมลสำหรับรับลิงก์ยืนยัน
4. คัดลอก Project URL และ anon/publishable key จากหน้า API settings ไปใส่ใน `assets/js/supabase-config.js`
   - ใช้ได้เฉพาะ anon/publishable key ในเว็บไซต์
   - ห้ามใส่ service_role/secret key ในไฟล์หน้าเว็บ
5. เผยแพร่เว็บผ่าน HTTPS แล้วสมัครสมาชิกใหม่หรือล็อกอินจากอุปกรณ์อื่นด้วยชื่อผู้ใช้และรหัสผ่านเดิม

ตรวจสอบใน SQL Editor ของโปรเจกต์เดียวกันได้ด้วย `select public.get_flowlock_user_count();` หากหน้าเว็บแจ้งว่าไม่พบ RPC ให้รัน `supabase/setup.sql` ซ้ำในโปรเจกต์นั้น เพื่อสร้างฟังก์ชันและรีโหลด schema cache

บัญชีเดิมที่สมัครก่อนเชื่อม Supabase จะถูกเก็บอยู่เฉพาะในเบราว์เซอร์เดิม ให้ออกจากระบบแล้วล็อกอินอีกครั้งจากเครื่องเดิมเพื่อย้ายบัญชีขึ้นระบบกลาง หลังย้ายแล้วจึงใช้บัญชีจากเครื่องอื่นได้ บัญชีเดิมที่ไม่มีข้อมูลในเบราว์เซอร์ต้นทางต้องสมัครใหม่

รูปโปรไฟล์ถูกเก็บใน private bucket และแต่ละบัญชีเข้าถึงได้เฉพาะไฟล์ของตนเอง

ระบบนับสมาชิกใช้ RPC ที่คืนเฉพาะจำนวน ไม่เปิดเผยรายชื่อหรือ UID ของสมาชิก ส่วนเพื่อนและรายการซื้อขายของเวอร์ชันนี้ยังเก็บในเบราว์เซอร์และไม่ได้ซิงก์ข้ามเครื่อง
